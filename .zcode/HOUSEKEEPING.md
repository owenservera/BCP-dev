## Rules

1. **Disposition classes.** COMMIT (evidence, receipts, first-party tooling) · PARK
   (`.gitignore`, stays on disk, revisit condition recorded) · DELETE (only with a lineage note
   and a decision entry — the default is never).
2. **Nothing untracked stays unexplained.** Any `git status --porcelain` entry must have a row
   below (open item or disposition log) within one session of appearing. Zero unexplained
   entries = clean.
3. **Noise classes that never get committed:** logs (`debug.log` and friends), generated test
   output, OS noise (`nul`, `Thumbs.db`, `Desktop.ini`), editor/temp debris. Evidence and
   receipts always get committed.
4. **`.zcodeignore` pairing:** its top section syncs from `.gitignore` (in-file sync marker);
   repo-specific custom rules go below the marker line so a sync cannot erase them.
5. **Parked ≠ gone.** Parked artifacts stay on disk and are revisited only when one becomes
   evidence for a live question (D-TEAM-014 revisit condition).

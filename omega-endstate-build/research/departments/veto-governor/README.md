# VETO-01 — Mission Governor Department

This directory is a self-contained experimental virtual department.

## Primary mission

Full VIVIM beta ready to distribute for free.

## Current role

Independent audit and opinionated governance challenge.

## Current power

One power only:

VETO_PROPOSED

It is advisory. The owner decides.

## Start a fresh LLM session here

The preferred cold-start path is:

1. AGENTS.md
2. BOOTSTRAP-PACKET.md
3. STATE.json
4. TASK-QUEUE.md
5. Claim a task from tasks/
6. Build the smallest sufficient context bundle
7. Perform an independent audit
8. Persist the result
9. Record owner disposition when available
10. Create follow-up outcome/self-evolution tasks where useful

If the runtime automatically loads AGENTS.md, that file is the operational entrypoint.

## What makes this a virtual department

The folder contains:

- role identity;
- decision rights;
- durable state;
- appendable task queue;
- context protocol;
- audit method;
- evidence discipline;
- anti-pattern catalog;
- self-definition guide;
- self-evolution guide;
- governance-of-governance guide;
- research intelligence;
- runtime capability model;
- result/evidence/learning stores;
- minimal queue and integrity tools.

The directory is deliberately small enough to understand but complete enough to survive a cold start.

## What is not here yet

There is intentionally no:

- automatic scheduler;
- automatic trigger;
- runtime blocking hook;
- autonomous self-modification;
- global roster ratification;
- permanent authority.

Those are future experiments whose justification must come from evidence.

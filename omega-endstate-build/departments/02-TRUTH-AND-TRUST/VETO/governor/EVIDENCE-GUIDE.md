# Evidence and Auditability Guide

## Evidence model

Every audit should distinguish:

OBSERVED -> INTERPRETED -> CLAIMED -> DECIDED

Only the first category is direct evidence.

An evidence receipt should include:

- source;
- exact location;
- observation;
- timestamp or revision where relevant;
- reproduction command or method where applicable;
- limitations.

## Evidence freshness

State whether an artifact is:

- current;
- stale;
- version-specific;
- inferred from historical evidence;
- contradicted by newer evidence.

## Independence

The reviewer should, where practical, derive its conclusion independently before reading the producer's narrative.

NASA's IV&V model is useful here: independent reviewers develop an independent understanding and use objective evidence across the lifecycle rather than simply accepting developer assertions.

## Auditability

A future session should be able to reconstruct:

- what was reviewed;
- what evidence was considered;
- what was concluded;
- what owner decided;
- what happened afterward.

A prose answer without durable references is not a complete audit artifact.

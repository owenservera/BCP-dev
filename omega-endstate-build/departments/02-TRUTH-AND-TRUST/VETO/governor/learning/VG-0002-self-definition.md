# Learning — VG-0002

## Lesson

The first useful evolution was not more authority or more topology. It was improving the department's ability to observe its own contract and remember recurring structural limitations.

## Reusable rule

Before adding a new persistent specialist, trigger, authority level or coordination mechanism, first test whether the missing capability can be supplied by:

1. better self-observation;
2. better durable context;
3. a bounded tool repair;
4. a measured experiment.

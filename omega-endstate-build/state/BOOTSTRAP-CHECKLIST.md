# Ω End-State Build — Bootstrap Checklist

Use this checklist for the first local Steward session and for recovery after a cold start.

## Repository safety

- [ ] Confirm repository root.
- [ ] Confirm remote.
- [ ] Fetch/prune refs.
- [ ] Confirm `team/omega-endstate` exists.
- [ ] Create an isolated Steward workspace.
- [ ] Confirm the Steward is not working directly on `main` or `team/omega-endstate`.
- [ ] Record agent ID, branch, workspace and base SHA.

## Reality reconstruction

- [ ] Read every file in `AGENTS_CONTEXT/ARCHITECTURE_STEWARD/OMEGA-ENDSTATE-BUILD-TEAM/`.
- [ ] Read the project home bootstrap files.
- [ ] Inspect current Ω implementation and authority.
- [ ] Inspect current cooperative-agent / Commons machinery.
- [ ] Inspect destination/product vision.
- [ ] Identify unknowns rather than filling gaps from assumption.

## Build the organization

- [ ] Establish Steward durable identity/context.
- [ ] Create minimum useful agent topology.
- [ ] Define ownership boundaries.
- [ ] Establish task/hand-off model.
- [ ] Establish evidence/verification model.
- [ ] Establish workspace allocator and branch controls.
- [ ] Establish team state and recovery model.

## Product route

- [ ] Form full-product understanding.
- [ ] Identify architectural choicepoints.
- [ ] Identify high-information experiments.
- [ ] Create the team's roadmap.
- [ ] Select first end-to-end build frontier.
- [ ] Record falsifiers / change triggers.

## Completion gate

Bootstrap is complete only when the team can safely say:

`we understand enough reality to build, we have a recoverable organization to build with, and we know what evidence would make us change course.`

## First build falsifiers

A build is invalidated by any of these:

1. product semantics become non-bypassably hard-coded in K0;
2. a second admission/authority path bypasses the governed boundary;
3. the research capability exists only as hidden infrastructure rather than a normal first-party plugin;
4. Work cannot remain attributable across execution/replacement;
5. Evidence cannot be tied to the resulting world state;
6. close/reopen changes canonical identity or loses canonical evidence;
7. swapping the realization requires changing semantic capability identity.

# Legacy Harvest Red Team

## RT-01 Green tests are semantic evidence, not live reality
Most proof is local/unit-level.

## RT-02 Durable row is not restart safety
Persisted records do not prove workers can reconstruct safely.

## RT-03 Replay can mutate history
Prefer branch/child Work so original evidence remains stable.

## RT-04 Retry can loop
Require bounded attempts, time and terminal classification.

## RT-05 Approval can be superficial
A gate is only as correct as the authority evaluation that created it.

## RT-06 Valid plan can have invalid realization
Account/session/browser resource/realization state is a separate runtime proof.

## RT-07 Scheduler cron is an evidence split
Runtime code and richer cron tests are not equivalent.

## RT-08 Resume validity is shallow
Cursor/provenance root is not a complete world snapshot.

## RT-09 Export is currently table-oriented
Round-trip canonical world/provenance/Work semantics still need proof.

## RT-10 Workspace is not world truth
Project/topic/canvas organization is a projection/relationship layer.

## RT-11 Objective is not necessarily another root ontology
Avoid recreating fragmentation through new peer entities.

## RT-12 Cache is not knowledge
Memoized output cannot be current external evidence.

## RT-13 Local planner is not canonical deterministic semantics
Keyword heuristics are fallback behavior, not the final planner law.

## RT-14 Fallback must respect identity
Provider/account substitution is an authority-governed change.

## RT-15 Background must remain attributable
Work continuing after user departure still needs actor, authority, evidence and return path.

## Final rule

No harvested mechanism becomes destination truth until it passes semantic characterization → destination mapping → authority compatibility → restart behavior → evidence classification → end-to-end falsifier.

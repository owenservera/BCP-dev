# Rejected Coupling

## RC-01 ORM proliferation
Do not map Legacy Prisma models one-to-one into Ω.

## RC-02 Engine-as-authority
Do not recreate workflow, autonomous, scheduler, retry and objective engines as independent top-level product authorities.

## RC-03 Direct browser paths
Generic Work composition must not bypass canonical Capability → Realization → Effect boundaries.

## RC-04 Stringly policy
Regex action labels may inform classification but cannot be constitutional authority.

## RC-05 Default allow
Legacy no-match policy defaults to allow. Reject this as destination authority; use explicit allow/ask/refuse/unavailable outcomes.

## RC-06 Runtime-local maps
Reject process-local active tasks/execution maps as durable Work truth.

## RC-07 Hard-coded defaults
Retry counts, timeouts and autonomous budgets belong to policy/configuration.

## RC-08 Tests as live proof
A passing fixture/unit test is not live external-realization evidence.

## RC-09 Shallow resume validity
Cursor + provenance root is insufficient for arbitrary world-dependent resume.

## RC-10 In-place replay mutation
Preserve historical execution; use branch/child Work.

## RC-11 Table export
Canonical export should not be a database-table reconstruction exercise.

## RC-12 Canvas as state
Canvas placement/layout remains a projection.

## RC-13 Provider fields everywhere
Keep source identity and realization refs explicit rather than copying provider fields into universal objects.

## RC-14 Stealth / anti-detection
Out of scope for this deterministic-first harvest.

## RC-15 Remote AI dependence
The core automation substrate must work without cloud AI or browser providers.

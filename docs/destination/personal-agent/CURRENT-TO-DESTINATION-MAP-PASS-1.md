## 2. How to read current status

GREEN = strong executable foundation.
YELLOW = substantial behavior exists but the destination abstraction is not yet unified.
ORANGE = design or partial implementation exists; cross-domain proof is missing.
RED = destination frontier requiring fresh characterization.

Current map:

GREEN: Vault, Law, Runtime/Plugin, Deterministic Language, Intent foundations.

RED: General Windows/desktop control, multi-device sovereign continuity, generic device/network resource model, complete external-world hydration.

## 6. Product maturity target

Every important capability should ultimately move through:

L0 Vision → L1 Prototype → L2 Working → L3 Integrated → L4 Live → L5 Productized → L6 Full vision.

Destination-grade means the behavior is not merely executable. It is addressable, inspectable, governed, evidence-backed, persistent, replaceable, and usable by an ordinary owner.

## 8. Architectural opinion

Do not create a giant PersonalAgentEngine to absorb all these concerns.

The better target is a thin, durable semantic control layer over strong existing primitives:

Personal Agent = principal-facing actor.
Spatial Intent Circuit = visual/writeable projection.
NLCL/Intent = deterministic semantic substrate.
World/Object = canonical addressed reality.
Work = durable execution subject.
Law = authority.
Vault/Evidence = truth and proof.
Provider/Account/Realization = bridge to external reality.
Self-Knowledge = derived operating picture.
Forge = evolution.

The implementation program should therefore optimize for joining these primitives rather than replacing them.

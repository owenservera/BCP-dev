# Deterministic-First Agentic Core

**Status:** RESEARCH PACKAGE LANDED — design candidate pending falsification.

The minimum VIVIM agentic substrate is a durable Work runtime with a versioned Plan, governed Capability execution, persistent Step/Attempt checkpoints, effect identities, temporal waits/triggers, verification/evidence, resource leases, human gates, and World/Attention integration.

`Trigger → Work → Plan → governed Step → Attempt/checkpoint → Verify → Evidence → World update → Attention/continuity`

An Agent is an optional role/policy over Work and Capabilities, not the canonical runtime root. AI is an optional bounded capability and never authority.

# World / Work / Attention Integration

World is canonical product reality: Things, relationships, revisions and artifacts. Work is canonical process reality: objectives, Plans, Steps, Attempts, waits, outcomes and evidence refs. Attention is derived: `World changes + Work changes + standing Intent + policy → Attention`.

A Work step mutates World only through a governed Capability. The mutation produces a World revision and evidence; Work advances after verification. Artifacts become canonical Objects/Files/Documents referenced by Work rather than duplicated in Work storage.

Child Work uses `parentWorkRef`, its own lifecycle and authority. Parent completion may depend on verified child outcomes. Canvas/web/chat are surfaces over World/Work/Attention, not canonical automation state.

# AI Insertion Boundary

AI is an optional capability. Allowed roles: Interpreter, Planner, Researcher, Diagnostician, Summarizer, Selector, or provider-specific realization.

`AI output → typed candidate → deterministic validation → authority → execution → verification → evidence`

AI never grants capabilities, changes Law, writes canonical Work state as truth, or bypasses verification. If AI is unavailable, deterministic Work continues; Work waits only when AI is genuinely required and records that dependency. Provider/model/session metadata belongs in provenance, not canonical object truth.

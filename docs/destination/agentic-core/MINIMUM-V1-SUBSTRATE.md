# Minimum V1 Substrate

## Required
1. Durable Work + revision.
2. Versioned Plan + deterministic validation.
3. Step DAG/dependency resolver.
4. Attempt record.
5. Governed Capability dispatch.
6. Effect identity/idempotency.
7. Durable reducer/checkpoint.
8. Evidence linkage.
9. Retry/timeout classification.
10. Durable time/event waits.
11. Resource leases/slots.
12. Human approval/input.
13. Deterministic verification.
14. Work→World mutation seam.
15. Work→Attention projection.
16. Restart/recovery harness.
17. Headless CLI execution.

## Not V1
Multi-agent society, self-modifying agent kernel, model-specific memory, browser automation, vector store as memory authority, distributed cluster scheduler, generalized compensation engine, visual workflow designer, separate Agent OS.

## Build order
A durable state → B execution → C temporal → D resources → E governance → F World/product integration → G optional AI adapters.

## Acceptance journey
Manual Work with deterministic Plan creates a local artifact, verifies it, records evidence, updates a World Object, waits on a timer, survives process termination, requests human approval, resumes the same Work, and emits Attention. No AI/browser is needed.

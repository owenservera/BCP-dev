
# World, Space, Workspace, Projection and Surface

> Classification: DERIVED — EVIDENCE-SUPPORTED + DESIGN-CANDIDATE

## 1. World

World is a derived, user-facing model of accessible canonical reality.

~~~text
canonical objects
       +
relationships
       +
scope / authority
       v
     WORLD
~~~

World must be reconstructable from canonical state.

It is not another database of the same objects.

## 2. Space

A Space is a durable semantic environment/context object.

It may express membership, contextual defaults, attention, semantic grouping and preferred surfaces.

A Space may be stored canonically because a user can create and name it. It must not become a hidden persistence silo.

## 3. Workspace

A Workspace is a configured interaction arrangement for a Space.

It can contain surface selections, panels, layouts, shortcuts and interaction preferences.

Workspace configuration is not the semantic source of what the world contains.

## 4. Projection

A projection is a derivation from canonical objects and relationships.

Examples:
- WorldModel;
- project summary;
- graph view;
- search result set;
- current context;
- ProviderKnowledgeView;
- self-knowledge view.

A projection should carry enough basis information to be regenerated and, where trust matters, prove what revisions it was based on.

## 5. Surface

A Surface is how a projection is experienced:
- canvas;
- card;
- table;
- conversation view;
- inspector;
- prompt interaction.

One canonical object may have many surfaces.

## 6. Layout

Spatial placement is projection state.

Moving an object on a canvas may change placement/configuration but must not implicitly mutate the object's semantic payload.

## 7. Current context

Current context is a derived lens over active space, focused objects, current work, recent events, selected attachments and applicable constraints.

It is not a second canonical store.

Status:
- World/projection separation: EVIDENCE-SUPPORTED.
- Canonical Space semantics: DESIGN-CANDIDATE.
- Workspace persistence shape: EXPERIMENT-REQUIRED.

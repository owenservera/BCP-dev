# Design Convergence

The final answer must reduce to a small canonical set.

Required diagram:

World
→ Canonical Objects
→ Relationships / Revisions / Evidence
→ Work references
→ Projections
→ Export / Restore

Then explicitly classify:
- core object types;
- typed roles;
- projections;
- caches;
- external references.

Reject universal semantic inheritance unless evidence requires it.

Reject UI-as-truth.

Reject duplicate content copies as canonical Work state.

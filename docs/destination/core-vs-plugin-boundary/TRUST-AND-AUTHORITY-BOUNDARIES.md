# Trust and Authority Boundaries

Trust is layered rather than binary.

K0 is the enforcement root. K1 is shared protocol meaning. System plugins are first-party composition members. Extension plugins are external composition members. Tooling is outside runtime authority.

Authority content belongs to law/policy plugins. K0 enforces that an invocation carries the required structural authority and capability evidence. User consent, standing, delegation, aperture and policy semantics remain domain content outside K0.

LLM output, provider responses, plugin claims and evidence are not automatically authority. Canonical history remains distinct from representation and confidence.

# Evolution Boundary Map

| Change | Core role | Plugin role | Required evidence |
|---|---|---|---|
| Plugin replacement | admit/activate safely | propose/implement | compatibility + verification |
| Provider healing | enforce admission | discover/repair | drift evidence + probation |
| Forge generation | admit result | generate/test | provenance + falsifier |
| Contract evolution | enforce version/integrity | compatibility/migration | impact + compatibility |
| Data migration | atomic safety | transform/reconcile | cited migration + rollback |
| Active Work implementation swap | preserve boundary | migrate/continue | semantic compatibility |
| Plugin retirement | prevent invalid boot | export/migrate | continuity evidence |
| Constitutional change | enforce special admission | propose evidence | owner authority + ratified change |

Core supplies safe mechanics; Evolution plugins supply analysis and domain semantics. No ordinary plugin may silently amend K0 law.

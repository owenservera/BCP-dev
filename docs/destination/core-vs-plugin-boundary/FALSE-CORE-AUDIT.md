# False Core Audit

Vault: essential persistence is not a Core reason; storage semantics must remain replaceable.

Work: durable Work is foundational but domain-semantic; Core needs a reference/protocol and safe routing, not orchestration semantics.

Intent/NLCL: central but replaceable; Core may enforce citation/gating, not interpretation.

Law: enforcement must be outside guest control, but policy meaning is plugin data.

Provider/Browser: external reality and Chrome/CDP are realizations, never kernel domains.

World/Object: stable identity contracts may be shared, but a complete world ontology in K0 would make product semantics constitutional.

Evidence: integrity primitives can be K0; evidence storage and epistemic semantics remain outside.

Forge: proposing/emitting changes is not K0; K0 only admits the resulting composition.

Surfaces/Canvas: representation is never source truth.

Resource economics: generic hard safety bounds may be K0; scheduling and economics are plugin policy.

Self-Knowledge: introspection is a projection over Core/contracts/plugins, not Core itself.

Product Instance: boot-critical composition remains a product domain.

General rule: everything depending on a component is not enough to make it Core. Identify the unsafe bypass that appears if it moves outward.

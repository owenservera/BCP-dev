# System Intelligence — Run Plan

> **Classification: DERIVED — PROPOSED**

## Wave 0 — apparatus

Done before archaeology:

- research charter;
- atomic schema;
- investigator protocol;
- six role briefs;
- synthesis specification;
- launch prompt;
- STATE;
- destination/V1 links.

## Wave 1 — parallel reconnaissance

Run SI-01 through SI-06 independently.

Rules:

- read-only;
- one role folder per investigator;
- no shared files;
- no production edits;
- exact evidence references;
- unknown and contradiction are explicit;
- investigators do not decide Ω law.

## Wave 2 — normalize

A synthesis agent merges the role packages into:

- ATOMS.json;
- EDGES.json;
- EVIDENCE.json.

Deduplicate by meaning/evidence, not filename or similarity alone.

## Wave 3 — graph analysis

Calculate:

- direct dependents;
- transitive dependents;
- journey reach;
- vertical-slice reach;
- workstream reach;
- proof reach;
- external-reality exposure;
- uncertainty;
- complexity.

## Wave 4 — targeted deep dives

Spawn only the investigations justified by Wave 3.

The default stopping point is not "all files read"; it is "all consequential atoms sufficiently understood."

## Wave 5 — reconciliation

Produce:

- SYSTEM-MAP;
- DEPENDENCY-MAP;
- RECONCILIATION;
- PRODUCT-TRACE;
- CRITICAL-PATHS;
- OPEN-FRONTIER;
- RED-TEAM-REPORT.

## Wave 6 — V1 handoff

The result should tell the build team:

1. what is already usable;
2. what can be harvested;
3. what must be built;
4. what must be proved first;
5. what remains genuinely unresolved;
6. which dependencies control the order.

Do not turn the research into an implementation plan until the evidence supports one.

## Source lineage

The research compares three evidence sources:

1. Legacy VIVIM — behavioral, UX, algorithmic, provider, and implementation evidence.
2. Standalone owenservera/vivim-omega — historical Ω source/reference and decision lineage.
3. BCP integrated Ω — current implementation evidence inside BCP-dev.

The emerging VIVIM product is the target being reconstructed from those sources plus destination product work. None of the historical codebases is automatically destination authority.

## Exit condition

This directory should eventually make it possible to trace a major destination capability:

PRODUCT OUTCOME → REQUIREMENT/JOURNEY → ATOM → DEPENDENCIES → IMPLEMENTATION → EVIDENCE

and in reverse:

SOURCE EVIDENCE → FINDING → ATOM → PRODUCT IMPACT

Once this is sufficient to choose the V1 build sequence, the detailed research layer becomes mostly archival and durable conclusions are promoted to the appropriate destination/program/decision home.

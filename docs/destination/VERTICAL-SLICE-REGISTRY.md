# VIVIM Destination — Vertical Slice Registry

> Classification: DERIVED — CURRENT PROGRAM VIEW
> Purpose: force architecture and product work to converge through small demonstrable end-to-end journeys.

## 1. Slice rule

A vertical slice is complete only when it crosses the relevant destination layers:

```
USER INTENT
→ WORLD / CONTEXT
→ CAPABILITY
→ ROUTING / AUTHORITY
→ WORK / EXECUTION
→ EVIDENCE
→ USER-VISIBLE RESULT
```

A slice may deliberately omit layers that are irrelevant to its outcome.

## 2. Slice ladder

| Slice | User outcome | Main dependencies | Current | Target |
|---|---|---|---:|---:|
| **VS0** | one governed external action | Runtime, Authority, Provider, Evidence | L3 code / L4 pending | L4 |
| **VS1** | install/start/reopen a local VIVIM world | Product Shell, Vault, World, Workspace | L0/L1 | L5 |
| **VS2** | import an AI conversation into a project | Import, Ontology, World, Memory, Context | L2/L3 | L5 |
| **VS3** | choose provider/account and perform work | Routing, Account, Realization, Authority | L1/L2 | L4/L5 |

| **VS7** | survive provider drift | Provider Lab, Healing, Forge, Routing | L2/L3 | L4/L6 |
| **VS8** | export and reconstruct the working environment | Vault, World, Config, Product Lifecycle | L2/L3 | L6 |

## 4. Slice completion states

| State | Meaning |
|---|---|
| **CHARACTERIZED** | boundaries and required dependencies known |
| **PROTOTYPED** | partial implementation exists |
| **WORKING** | bounded reproducible scenario succeeds |
| **INTEGRATED** | real neighboring destination systems compose |
| **LIVE** | real external/owner environment proven |
| **PRODUCTIZED** | normal-user lifecycle works |
| **DESTINATION-GRADE** | sovereignty/recovery/replaceability/evolution criteria satisfied |

## 5. First three slices after V0

### VS1 — Run my VIVIM

Minimum outcome:

> install → start → local durable world → reopen → state remains.

Must answer:

- where data lives;
- what the default environment is;
- what the first-run experience is;
- what survives restart;
- what recovery means.

### VS2 — Bring my AI history

Minimum outcome:

> import supported history → project relationship → browse/search/inspect → provenance preserved.

Must answer:

- supported import sources;
- source genealogy;
- project linkage;
- memory creation/correction;
- search/context behavior.

### VS3 — Act across providers

Minimum outcome:

> choose account/provider/model → express intent → route → authorize → act → inspect result.

Must prove the account selected by the user is the account actually used.

A slice is the unit that demonstrates the architecture is becoming the product.

# handoffs/ — Agent Continuity Records

> **Classification: convention (DERIVED — CURRENT); each handoff carries its own banner**

File: `handoffs/HANDOFF-<id>.md` (zero-padded, e.g. HANDOFF-001). One handoff
per meaningful transfer. Receiving agent continues from the handoff (+ linked
reads) without reconstructing the sender's reasoning.

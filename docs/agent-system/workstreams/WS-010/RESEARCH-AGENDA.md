# WS-010 — Initial Research Agenda

> **Classification: DERIVED — PROPOSED V0**

## Round 0 — Grounding

Verify the V0 blueprint against actual current repository mechanisms.

Deliverable: source inventory, contradictions and blueprint corrections.

## Round 1 — Semantic model

Test entity identity, contextual descriptions, state dimensions, relationship
semantics and provenance.

Deliverable: model delta and falsifier results.

## Round 2 — Visual model

Test canvas territories, semantic zoom, visual state grammar, attention and
cross-view projections.

Deliverable: visual specification or bounded interactive prototype after the
semantic model is stable enough.

## Round 3 — Thin data projection

Build a read-only Program Map using a deliberately small corpus:

- program/territories;
- P1-01;
- P1-02;
- one Ω decision;
- one BCP state item;
- one agent;
- one Git commit/PR;
- one evidence artifact;
- one known unknown/conflict.

Deliverable: reproducible derived model + renderer.

## Round 4 — Adversarial verification

Run the proof suite in PROOF-PLAN.md.

Deliverable: pass/fail matrix and unresolved boundary conditions.

## Round 5 — Owner gate

Owner decides whether V0 is ready to proceed toward product implementation.

No implementation expansion is implied by a green research round.

# Ω Evolution Team — Decision Index

> Status: SEED
> This is a lightweight index, not a second decision system.

Consequential team decisions should be recorded here or in a linked decision record when the decision changes product/system direction.

Suggested fields:

- decision ID;
- date;
- status;
- question;
- decision;
- alternatives considered;
- evidence;
- falsifier / validation condition;
- affected Ω law or architecture;
- compatibility/integration note;
- supersedes / superseded by.

The team may later replace this index with a better mechanism if experience shows that it is insufficient.

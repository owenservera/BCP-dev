## Path B starting contract

The team is given:

- Ω as the technical starting substrate;
- the VIVIM / Sovereign Canvas end-state vision;
- full access to everything else in the repository as optional context, evidence and source material.

It is **not** given a migration mandate.

It is **not** required to inherit the current P1/CFA roadmap.

It is **not** required to preserve legacy VIVIM architecture.

It is **not** required to preserve current Ω architecture or law when the end state requires a different solution.

The team determines its own development operating system, agent topology, roadmap, sequencing, architecture and implementation strategy.

The objective is the **entire end-state solution**, not an incremental Ω maintenance program.

## Relationship between paths

The paths may inspect, learn from, or eventually integrate with one another, but neither is subordinate to the other.

Branch-local decisions remain branch-local until explicitly reconciled.

## Short rationale (why this ranking)

1. **Observation before assertion (1, 4):** a team with full-machine hands but no
   governed eyes manufactures World truth from reads. Search + explicit observation
   points come first because every other tool consumes their output.
2. **Context before scale (2, 6, 9):** unbounded context is how World meaning dies
   at team scale — silent truncation, drifted lore, collapsed epistemics. The
   assembler, replay harness, and epistemic query envelope are one bounded-projection
   stack, ordered by build dependency.
3. **Identity discipline before integration (3, 5, 7):** the more machine surface the
   team touches, the more identity schemes collide. Five-state resolution, explicit
   correspondence, and per-claim basis are the minimum that prevents false
   equivalence from compounding.
4. **Relations and viewpoints last (8, 10):** topology meaning and scoped views are
   high-leverage but depend on 1–9 being honest; a relationship view over
   un-based claims is a rumor graph, and enforced views without CFA-04 are a
   boundary violation. Both are characterized descriptively now, gated for more later.

Deliberate non-top-10 (with reason, not oversight): temporal reconciliation harness
(gated until M4 contract selection — roadmap); scale benchmark (NOT YET NEEDED —
roadmap); live provider lab (peer-owned, CFA-06 contextual input); MCP mesh servers
(Phase 3, CFA-10 operates / CFA-04 gates — noted as transport, not characterized here);
universal graph DB / universal Event-State primitive / second World store inside
Context (explicitly rejected by CFA-01 doctrine).

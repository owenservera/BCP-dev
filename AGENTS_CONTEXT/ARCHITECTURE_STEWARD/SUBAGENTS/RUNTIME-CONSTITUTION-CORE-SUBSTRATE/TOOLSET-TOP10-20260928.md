## Rationale (why this order)

Ranks 1–4 are load-bearing for full machine access specifically: without OS
containment (1), every shell grant is unbounded; without identity gating (2),
every headless run may execute as the wrong (most-privileged) agent with exit
0; without precedence proof (3), every deny may be illusory; without spawn
discipline (4), the team graph is unenforceable. Ranks 5–6 close the highest-risk
admission gap (B1). Ranks 7–9 make safety hold across time, replacement, and
resource pressure. Rank 10 makes all of it verifiable instead of asserted —
without it, ranks 1–9 degrade to claims.

# PERSONAL_AGENT Context

Cold-start context for VIVIM's Personal Agent, Self-Knowledge, Deterministic Command Language, and Symbolic Command System.

## Core proposition
VIVIM should be able to explain itself to its user: identity, state, capabilities, configuration, dependencies, history, decisions, evidence, current Work, and how commands were interpreted.

The running product should be the most useful documentation of the running product.

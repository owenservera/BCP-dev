## Critical distinction
`important`, `first-party`, `always-installed`, and `security-sensitive` do not by themselves make something Core.

Core is the minimum non-bypassable, domain-neutral mechanism required to make plugins safely exist.

System plugins are still plugins even when they are essential to the default VIVIM composition.

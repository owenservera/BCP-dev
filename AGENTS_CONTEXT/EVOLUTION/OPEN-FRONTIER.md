# Open Frontier

> Current phase: support the first compositional product build; research only when an evolution question blocks a real implementation decision.

Evolution remains a cross-cutting requirement, but the entire evolution model does not need to be completed before coding begins.

## First-build priorities

- capability/composition replacement semantics needed by the first reference pieces;
- configuration and state continuity for those pieces;
- rollback/quarantine where a real first-build change requires it;
- evidence continuity across the changes we actually ship;
- Product Instance continuity across the first close/reopen path;
- user-created composition change where it is part of the first factory demonstration.

## Deferred research frontier

EF-01 through EF-13 remain valid open questions. Do not launch a new deep research pass unless one of them can materially change an active build decision.

Existing research and Ω mechanisms should be reused first.

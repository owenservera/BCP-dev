Stack — top depends on bottom, never the reverse

Dependency rule (enforced by tests/arch/kernel-boundary.test.ts): plugin-kernel → {shared, src/schema, src/storage/contracts, src/lib} only. Engines never import from plugin-kernel. PluginContext is the only capability object a plugin receives. Red dashed arrows are violations by construction.

How to use this map

  • Click a layer to highlight its files and the allowed downward arrows. Click again to clear.
  • Click a contribution (schema / service / ui …) to highlight the exact file path from manifest → registry → store → renderer.
  • Toggle v2 to visually scope v1: v2 contributions dim when off — v1 = 3 axes only.
  • Search filters files and permission strings across all layers. Empty search restores full map.
  • Keep MAP.md and this file's LAYERS const in sync — same PR.

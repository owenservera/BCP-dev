Fix 1 — Stream Parser Recursion Guard VERIFIED

Bug: parse() triggers async repair (autoRepairInFlight) that calls parse() again → unbounded recursion loop (parse → repair → parse → repair...). Engine hangs forever.

Fix: Added autoRepairInFlight Set guard. If repair in progress, skips repair (prevents loop). Set cleared after repair.

Evidence: File tests/unit/engines/stream-parser.test.ts (commit reference 77dcf94). Individual: 10/10 PASS. Full-dir: 2,077 pass / 22 fail / 0 hang.

Fix 2 — Sandbox QuickJS Hardening VERIFIED

Bug: Sandbox (SandboxRunner) executes QuickJS without budget limits, per-slug serialization, bounded retirement, context capture, or exit hooks. Memory leaks + unbounded execution.

Fix (6 measures): Budget (computeMemoryUsage); Serialization (slugQueues + runId); Retirement (RETIRED_CAP = 16, retireEntry()); Context Capture (captureCtx(), fnHandleRegistry); Exit Hook (disposeEntry()); Registry Cleanup (fnHandleRegistry disposed before pair).

Evidence: File sandbox-quickjs/ (commit reference b80d442). Full-dir: verified.

Fix 3 — Chrome Governor Mock Wiring VERIFIED

Bug: Tests spawn real Chrome instances via FleetSupervisor instead of mock supervisor/transport/event bus. Tests hang.

Fix: Wired mock supervisor (4th arg), transport (3rd arg), event bus (2nd arg).

Evidence: File chrome-governor/ (commit reference 79ff842). Individual: 32/32 PASS. Full-dir: verified.
